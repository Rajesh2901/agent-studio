## ⚡ Quick Start

### 1. Launch via PowerShell or Batch
Run the provided one-click launcher:
```powershell
.\run.ps1
```
Or with Windows Command Prompt:
```cmd
run.bat
```

### 2. Manual Launch
```bash
python server.py
```
Open **[http://localhost:8050](http://localhost:8050)** in your browser.

### 3. Serverless / Static Web Access
AgentStudio OS includes a standalone **client-side execution engine** that runs 100% statically on **[GitHub Pages](https://rajesh2901.github.io/agent-studio/)** without requiring a local Python server.

## 🌐 Enterprise UI/UX Design System (v3.0)

- **Layout Topology**: Dual Z-pattern (executive scan) and F-pattern (analytical drill-down) with an 8:4 asymmetric analysis zone.
- **Visual Grid**: Strict 8pt grid cadence (4px micro, 8/16/24/32px containers).
